# Moshield Default Theme

## Architecture & Folders

- **`assets/`**: Contains all static assets required by the theme. This includes CSS stylesheets (e.g. `base.css`), Javascript logic files, and SVG icons.
- **`blocks/`**: Modular `.liquid` templates that can be used interchangeably across multiple sections, providing a scalable building block system.
- **`config/`**: Configuration metadata. `settings_schema.json` defines the options presented in the Shopify theme editor, while `settings_data.json` holds the configured default values.
- **`layout/`**: Root templates defining the wrapper HTML of your store, including `theme.liquid` (the primary layout).
- **`locales/`**: i18n JSON files covering multiple languages to keep the theme natively translatable.
- **`sections/`**: Independent UI sections accessible within the Shopify Theme Editor for drag-and-drop page assembly.
- **`snippets/`**: Isolated helper components typically rendered via Liquid's `{% render 'snippet-name' %}` tag to maintain DRY principles.
- **`templates/`**: JSON mapping and traditional `.liquid` files dictating the layout configuration of different page types like products, collections, pages, or blogs.

## Getting Started

1. **Working on Design**: When you need to edit styling or scripting, navigate to `assets/`. UI elements can be updated in `sections/` and `snippets/`.
2. **Shopify Integration**: The theme uses JSON templates, making it fully compatible with Shopify OS 2.0 section formatting.
3. **Re-importing**: Compress the folders back into a `.zip` archive to upload to your Shopify account, or link your local directory with the Shopify CLI (`shopify theme dev`) for real-time local development.
